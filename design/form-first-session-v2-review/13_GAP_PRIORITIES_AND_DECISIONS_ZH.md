# 研究结论→决策→后续行动清单（避免无限加功能）

**仅作为产品评审建议**。用户授权本轮全面研究并推送 GitHub，但未授权改 FORM 正式 App、模型预算、订阅、免费试用、支付或部署。评估时坚持真实用户体验优于文档/测试数量。

## A. 优先级与理由

| 优先级 | 问题 | 价值与最小动作 | 发布/设计闸门 |
|---|---|---|---|
| P0 | 首屏没有授权且能证明同车变好的案例 | 准备少量普通轿车/SUV/皮卡的**真实同车、相近角度**输出，筛选最能激发上传欲望的一例 | 素材授权、车型保真、改动明确、不得夸大 |
| P0 | 开屏让用户读产品说明而非看车 | 单幅高质量 before/after 为主视觉， CTA 对应当前搭配 | 5 秒目标车主测试 |
| P0 | “试用”与价格误导 | 保持次数包，实际报价/结果数量在提交前明示；无免费承诺 | 钱包/StoreKit/文案审核 |
| P0 | 用户上传后依然看不清“自己的车” | 用户原图/历史版本大图为主体、少数底部改装项 | 小屏实测、不假预览 |
| P1 | 大量风格图加载失败后选不下去 | 主案例优先加载、本地获授权离线缩略图、加载/失败说明与重试 | 慢网模拟，不能靠空卡转化 |
| P1 | “复杂风格/Extra/颜色”让新手困惑 | 风格只是灵感，车色/质感分离，可选编辑项必须真正支持 | 少量方向质量准入 |
| P1 | 错图/低质照片导入 | 好坏照片示意、解码/大小检查、换图，不假称 AI 自动识车 | 相册权限、异常/隐私联测 |
| P1 | 看到付费或离开 App 丢失草稿 | 一次确认一个任务，购买取消/后台恢复保持选图和意图 | 客户端/服务端幂等联测 |
| P1 | 结果给出后没有继续理由 | 前后比较→保存/收藏→选择一处继续修改 | F16/F17、真实模型质量 |
| P2 | 想试娱乐化变形/视频 | 暂时研究假设，不在首版引入 | 新商业决策和成本评估前禁止 |
| P2 | 需要更多汽车品牌/SKU/3D | 目前不是对普通车主首三分钟有意义的核心 | 真实精度能力和预算缺口 |

## B. 绝不能提前变为默认实现的想法

- 把**Modyfy 四步**当作 FORM 规定的四步：顺序冗长，FORM 已支持“案例主路/单项副路”，应缩短。
- 把 Mody 底部 GARAGE 截图当作可准确识别每片车身的功能证明。
- 提前设定“最美的一张广告图”而不实际测试与车主的情感关联。
- 把用户点击首页主 CTA 算成成功：还须知道用户是否相信结果、愿否真正上传、是否理解一次费用。
- 假定竞争对手每个菜单都在生产可靠运行：只有界面存在和部分操作可见的事实。
- 直接迁移 Modyfy订阅机制、评分弹窗、奖章、夸张用户量、频繁付费墙。
- 立刻选供应商/逆向提示词或未经授权发起收费生成；REA 和模型另案处理。

## C. 下一轮真正需要的输入（不阻塞文档工作）

- 少量授权真实改装案例与素材来源、可展示范围；要证明“同车同角度，不换身份”。
- 独立完成的 FORM 模型质量评估（后续专案）。
- 真实 Apple 次数包产品配置与显示价格（后续高风险任务）。
- 8–12 位目标车主的无提示体验观察。
- 对现有中文 A/B HTML 的主入口选择结果；若仍无上传冲动，推翻旧视觉，不要小修小补。

## E. 给产品负责人看的判定

不要以“漂亮/页面很多/测试都绿了”来批准。只问：
1. 有没有可发布的、真实的、足够让普通车主代入的汽车前后变化？
2. 他是否无需指导就愿意点“用在我的车上”，而且知道不是免费生成？
3. 第一张真的返回后，他是否还认得出自己的车，愿不愿意继续下一次？

任何核心问题答不上来，保持“研究可读／设计待验证”，不进入发布。
