## 研究系统与 FORM 开发的防火墙

- 研究源：官方 App Store / 开发者网站 / 公开评论 / 经允许的真实使用观察 / 经过许可的 REA 静态与网站分析。
- 证据审查：来源、App ID、地区、时间、版本、授权、方法、可信等级、反证与未知项。不可用评价数量推导收入和转化率。
- 决策：找出“用户完成一次有效汽车修改”的体验缺口；先验证，后决定。竞品功能不是对 FORM 需求的自动批准。
- 开发：FORM 的 Codex 仅按照冻结 V2.2 任务、PR 和审查关口实施。任何研究发现必须先进入独立建议/决策评审；不得直接改写任务卡、AGENTS.md、数据库或 UI。
- 发布：真实模型质量、财务/隐私、Apple 真机和 App Store 审核有各自发布门槛；研究不替代任何一种验证。

**当前活跃开发：** 23chen990/form-car-studio 的 codex/form-v2-implementation / Draft PR #3。此研究分支不得写入该分支，不能合并、重设、变基或触发付费 API。所有研究材料停在单独的文档 PR 等待审核。旧的 V2.2 规范和 43 文件冻结哈希均不修改。
