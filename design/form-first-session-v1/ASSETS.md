# Visual asset provenance

All car art in this delivery is original SVG geometry authored for this prototype, inside prototype/app.mjs (car function). No third-party car photo, automotive logo, competitor screenshot, downloaded font or stock asset is embedded.
The same illustration is recolored as an explicit UI example. It is NOT model generation, exact physical materials, a specific vehicle configuration, or evidence of production AI quality.
System fonts are requested; no font files are redistributed. Small interface icons are simple original SVG line paths defined in the same file.
Runtime screenshots in evidence/ capture this prototype only, using those assets and synthetic fixtures.
The existing repository's demo photograph is not copied: its publication rights are recorded as unverified in docs/OPEN_SOURCE.md.
Before release, the owner must supply authorized representative vehicle photographs and reproducible outputs from the chosen model/profile; pair original and result by source ID and retain permission/evaluation records privately.
Never remove the illustration label and sell these images as results of an uploaded user car.
