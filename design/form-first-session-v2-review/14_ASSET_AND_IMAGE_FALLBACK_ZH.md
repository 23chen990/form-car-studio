# FORM 样例车图、授权与弱网策略

本文件结合两份录屏中出现的黑图、加载旋转与图片可能不完整情况，形成**FORM 的预防性要求**。用户报告的手机卡顿意味着我们无法确定竞品图片未加载的根因或平均故障率。不可把“视频上数十秒没出图”直接计算为产品线上加载耗时。

## 真实样例制作标准（前提是后续有真实模型预算/已有可授权案例）

| 条件 | 必须满足 |
|---|---|
| 同车 | before/after 是同一辆车、主体身份与主要外形可对应；不能把两辆相似车型拼接 |
| 构图 | 相近位置、镜头高度和方向；如构图差异显著需明确标注，不能拖拽比较造成假精准 |
| 变化点 | 车色/漆面、经过核验的轮毂/外观方向清晰，绝非仅加对比度和虚假色调 |
| 原车保留 | 车门、车身比例、车牌/隐私遮挡和车窗位置有人工复审；模型幻想的零件不能宣传为实体适配 |
| 多样性 | 首屏至少有对普通车主有代入感的日常车型，而非只放 Ferrari 超跑/极端宽体 |
| 权利 | 原始车图版权、车主肖像/车牌、商标、生成商用授权、发布地域与期限应记录在私有来源台账 |
| 真实声明 | 展示实际所用产品/供应商配置与输出状态。若仅为视觉概念，用明显的“概念示意，非 FORM 实测”标签，不作为付费说服证据 |
| 可验证证据 | 存在输入图→已知正式任务→输出图的安全审查记录（不公开隐私图/秘钥），可复查关键真实性 |

## 优先级加载策略（建议，需工程评审）

- **首屏一组案例优先**：优先提供小体积、预先打包的获授权缩略图或已审定可缓存形式；次要案例延后加载，降低灰卡占屏。
- **固定容器与占位**：图片尚未解码也保留比例，不让 CTA 大幅跳动。
- **失败时可理解**：“示例暂时没加载出来，重试”而不是空白、转圈无尽循环；允许返回或换另一幅已可用图。
- **弱网与重试**：区分本地打包失败、网络缺失、远端地址过期；本地示例可以独立显示，用户选图不应因为营销图片断网被阻止。
- **展示层取舍**：真实用户原图和所选历史版本优先显示；不可用远端广告图覆盖用户图片。
- **节省资源**：缩略图用于列表，原图用于必要比较；不要默认加载一屏二十张高分辨率汽车图，更不要对浏览行为调用模型。
- **隐私**：本地预览时避免误上传给统计 SDK，只有确实需要和用户同意后发服务端；真实图片绝不进入公共 GitHub、日志、截图附件。
- **不假结果**：当实际生成/输出不可用时，只展示原图和待生成意图；不使用 CSS 颜色覆盖、模糊合成或预置另一辆车冒充生成结果。

## 素材缺口台账（待补，不可造假）

| 用途 | 当前状态 | 合法下一步 |
|---|---|---|
| 上线首页主 Before/After | **缺真实可发布 FORM 输出** | 获授权案例和质量评估，不得擅自购买模型调用 |
| 车身改色案例 | **需要真实同车能力验证** | 先做一小组明确的通用汽车测试 |
| 轮毂案例 | **通用轮毂效果仍受能力闸门约束** | 不先开放 SKU/品牌与精确规格 |
| 选图好坏示例 | **须自主摄影/许可明确素材** | 不能抓 App Store 截图用于产品宣传 |
| 概念 UI 样图 | **可内部设计研究** | 清楚标“概念示意”且不可转正式宣传 |
| 用户提供竞品录屏/相册画面 | **私有研究证据** | 只入库脱敏文字与哈希，不提交画面 |
