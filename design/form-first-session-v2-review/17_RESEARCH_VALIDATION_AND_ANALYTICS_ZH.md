# 小成本验证与行为分析｜后续研究建议

FORM 不追求成为全能汽车编辑头部平台；需要把有限成本押在最能提高**真实上传动机与实际满意度**的环节。本文件为**未执行的建议**，不授权付费模型调用或接入新的追踪 SDK。

## A. 一轮低成本定性验证

对象：8–12 位普通海外 iPhone 车主，车型覆盖轿车、SUV、皮卡，含非重度改装用户。每人 10–15 分钟；视频/照片素材权需另获允许，不把私人车图放到公开仓库。

对照材料：
- 旧版概念矢量/未通过首屏（对照旧问题）
- V2 A：同车变化先行（仍是未授权概念素材的视觉候选）
- V2 B：先选部件（仍是未授权概念素材的视觉候选）
- 未来的**真实发布许可 Before/After**（最后单独验收，不与概念图混为一组结果）

评估目标：用户无需说明就理解“自己的车”价值；愿意在 30 秒内主动选照片，并说得清为什么；在确认页不误以为免费、不会把模拟图当真实产出。记录原话和操作证据，不用小样本声称统计显著。

## B. 最少一批可用的产品诊断事件（仅在已同意、合法且符合 D23 的前提下）

| 事件（候选） | 目的 | 允许的非敏感字段 | 禁止 |
|---|---|---|---|
| first_view | 知道首次入口真正被展示 | screen_variant、app_version、locale | 上传原图、车牌、设备指纹 |
| case_view / compare_used | 哪些真实案例引发关注 | approved_case_id、interaction_type | 完整图片 URL 或私人图 |
| upload_intent | 是否主动想上传 | entry_case_id、entry_surface | 猜测用户心理/隐私标签 |
| photo_selected_local | 是否实际完成本地选图 | non-identifying result status | 原图内容、EXIF、相册路径、车牌 |
| photo_permission_declined | 权限阻塞在哪里 | screen id、result code | 持久跟踪拒绝者 |
| draft_ready / quote_viewed | 费用是否被看到 | supported_feature_codes、quote_status | 原始描述全文、卡号/交易收据 |
| purchase_canceled | 离开原因需要区分（若可合法记录） | recovery_screen、status | 付款载荷、Apple 身份信息 |
| job_started / result_shown | 真实链路与质量问题 | job status／匿名任务聚合计数 | 敏感图、精确位置 |
| compare_after_result / refine_requested | 第一张结果后的价值反应 | action code、whether_new_job | 私人前后图 |

先画清事件定义和隐私边界，再决定是否真的上线；避免把研究事件变为新的大型 SDK 与维护项目。实际生产诊断以 F28 和已批准法律/隐私策略为准。

## C. 漏斗和质量指标：先定义，后测量

- **前 5 秒价值理解**：用户自己表述产品功能，研究人员不得先讲。
- **前 30 秒上传动机**：是否自发寻找上传入口，以及具体阻碍。
- **本地选择完成**：看到真实选中的原图，不等于已经成功提交私有上传。
- **支付认知**：准确知道是否要花钱、一次多少张、购买后不会自动生成。
- **真实输出质量**：车型/构图/目标改动可比性，需保留授权输入输出评审证据。
- **继续微调行为**：第一张真实图之后实际发起下一次编辑（不是单看点击率）。
- **经济底线**：真实供应商单位成本、失败调用外部成本与可退款/补偿成本；只有经批准模型账本才能测。

## D. 失败时该怎么调整（防止盲目改配色）

| 观察失败 | 首先排查 | 不应该直接做 |
|---|---|---|
| 用户不知道 App 有何用途 | 案例前后是否同车、改动是否显眼、CTA 是否明确 | 加一段功能说明 |
| 用户觉得好看但不愿给照片 | 可信度、版权/隐私解释、价格透明、照片教程 | 假装免费、强制登录 |
| 用户上传后迷茫 | 原图是否被压缩成小角落、改动意图是否持续显示 | 增加十个风格选项 |
| 用户选了非车截图 | 图片选择防错、真实能力边界与替换动作 | 欺骗式“AI 已识别汽车” |
| 用户卡在风格列表 | 样例缩略图授权/加载、分组与默认推荐 | 无限加载动画 |
| 用户不理解收费 | “trial”是否存在双关、真实服务端 quote 是否露出 | 把价格藏到分析动画之后 |
| 结果后不继续改 | 是否足够像自己的车，效果是否满意，单项再次编辑是否清楚 | 自动弹充值或奖励假进度 |

## E. 测量可信度等级

`单个用户录屏` 是高价值的具体行为样本，不代表平均转化；`单个评价` 是访谈线索，不代表舆情统计；`原型测试通过` 证明所测路径没有明显编码错误，不证明愿意付费；`有真实输出案例` 证明指定样本可用，不等于模型在全部车型上的成功率。

完成真人研究和模型验证前，所有数字指标状态写 `NOT_MEASURED`，不能用预设目标替代实际结果。
