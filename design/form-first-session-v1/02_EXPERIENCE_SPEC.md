# 前三分钟体验规格

## A. 我们真正优化的目标

不是“180秒内一定成交”。默认付费路径的目标，是让用户很快看懂效果、用合适照片形成一个具体创作意图，并清楚决定是否支付；已有余额/获批试用路径，还可提交任务并知道怎样回来查看。

将总时长拆成 `time_to_intent`、`time_to_submission`、`generation_latency`、`time_to_first_usable_result`。其中模型延迟不由 UI 伪造。

| 观察窗口（设计目标，不是实测） | 用户问题 | 应有回答 |
|---|---|---|
| 0–10秒 | 这是干什么的？普通车也可以吗？ | 同一辆车前后对比、直白价值文字、一个主入口。 |
| 10–30秒 | 这几个风格我选哪个？ | 先一个精选方向；可切换两个其他方向；不用车型问卷或提示词。 |
| 30–60秒 | 我的照片能用吗？会马上上传吗？ | 全车本地预览、可换图、处理前明确同意。 |
| 60–120秒 | 为什么登录？花多少？做哪一张？ | 账号价值、真实价格/次数、基础图和修改清单；付款不触发意外生图。 |
| 120–180秒及以后 | 我是不是卡住了？可以离开吗？ | 真实任务状态、单个任务入口、清楚的失败/迟到处理。 |
| 结果返回后 | 这是我的车吗？还要付钱才能留吗？ | 原图直接对比、成功已保存、自由导出、主动微调。 |

## B. 只维护一条主流程，商业条件是分支

主路径：
`Discover → Local photo → Review → [Account] → [Data consent] → Upload/precheck/quote → [Credits] → Explicit create → Task → Result → Optional refine`

括号项：已有有效状态时跳过；不能为凑仪式感重复确认。
**技术准备与最后消费确认不同。** 准备成功后，按钮必须显示当前报价。任何登录、授权、购买回调都不能代替最后一次确认开始新生成。

### 默认付费路径 A（建议实现默认）
免费查看示例 → 选自己的照片（本地）→ 在准备阶段知道会使用次数 → 登录 → 明确照片存储和处理同意 → 上传/获得有效方案报价 → 余额不足时查看真实商品 → 原生内购 → 服务端确认入账 → 回到原草稿/重新核对报价 → 主动创建。

- 上传前必须拿到真实政策/供应商说明；不因准备报价而越过同意。
- 付费前至少完成本地文件可读性和已知能力检查；正式可执行报价优先在付费前取得。不要卖一个已知不支持的请求。
- 产品可在选图前展示“创建使用次数”和价格入口，**不可假装首次免费**。
- 用户购买的是次数包，不是强迫立刻执行的某次任务；支付中断或退出后仍可使用已到账余额。
- 不以“先看自己车辆结果再买”描述本路径。

### 受控体验路径 B（只作实验）
后端明确批准试用、稳定账号满足资格、预算可承受 → 给予一次真实试用权益 → 一次确认创建 → 自由保存结果 → 主动微调或新风格时才出现购买入口。
不是“先做结果再突然模糊遮挡”，不是两次或无限免费，默认不激活。

### 已有用户 C
直接展示最近自有作品/活动任务；已有有效账号/同意不重复拦截。优先恢复任务和未完成购买，不将“第二次打开”再次当新客发试用。

## C. 页面及弹层

### S01 Discover / 主发现页
**用户任务：** 看见变化并愿意尝试。
- 顶部 FORM、帮助；未登录不强调“0 credits”。
- 标题 `Same car. A new feeling.`；补充 `Find a look you love. Make it yours.`
- 首屏一个全车案例；可点击 `Original / New look` 比较，不依赖长按。案例名始终可见。
- 三个首层精选位置：Street Sport / Quiet Detail / Color Story。它们为可用 styleId 的展示候选，不是新建三种生产能力。
- 主 CTA `Try this look on my car` 固定在不遮挡内容的底部操作区域。它直接去选图，不再强制详情。
- 次入口 `Change one detail`，直接使用原图，不混入整车预设。
- 选图前提示 `Explore examples free. Creating on your car uses credits.`；不得以小到不可读的文字隐藏。
- 比较、切风格、导航：零生图、零次数预留、零用户照片上传。
- 只有已完成生成的真实、获授权案例才能宣传成产品效果；原型使用 `Illustrated example — not an AI result`。

### S02 Photo / 选图
**用户任务：** 找到可用照片并确定会发生什么。
- `Choose a photo` 调用系统选择器；相机在独立点击时请求。用户取消选择器原地返回，不创建空项目。
- 拍摄建议只保留：全车可见、光线清楚、一辆车；三分之四/侧面是建议，不机械拒绝其他可用照片。
- 避免“识别成功：BMW M3”等未实际运行的识别文案。
- 本地预览采用 contain，保留轮毂和保险杠；按需换图，不强制裁剪。
- `Remove selection` 只清本地选择；不等于删除已上传作品。
- 明确处理：HEIC 转换、iCloud 下载中断、权限拒绝、坏文件、大小/像素限制。平台不支持时给可执行替代，不只把 accept 字符串扩展。
- 原型允许真实本地图片预览，但阻止模拟输出，必须换到示意图才能演示完整路径。

### S03 Review / 创建准备与最终确认
**用户任务：** 我愿意为这一个明确请求消耗一次。
- 显示实际基础图缩略图、所在项目、原图或明确版本；名称不是权限凭证。
- 显示 `Requested changes` 和 `Keep unchanged`。后者是编辑约束，不能写成已经验证的结果。
- 显示一个输出、1 credit；币价只在购买处来自 StoreKit。保留/比较/导出不额外生图。
- 主按钮由状态驱动，见 `03_STATE_CONTRACT.md` 和 `flow-policy.mjs`，不是永远禁用而没有原因。
- 无变化时说明为什么不能提交。旧请求颜色相同不证明图片真的没变化，生产 no-op 必须由已验证基础观察判断。
- 明确确认才持久化 submissionId 并 POST；所有影响图像/计费的参数在报价中冻结。
- Back、登录取消、支付取消保留草稿。更换基础版本前有“保留当前草稿/放弃修改”明确选择，不悄悄编辑最新版。

### M01 Account / 登录
仅在需要稳定云端身份、购买或试用时出现。
说明 `Keep your looks and purchases together.`，生产使用 Apple 官方原生按钮；不再追问已隐藏的邮箱，不索取密码、不让用户先起用户名。
用户关闭后回到同一基础图和选项，不“回首页重来”。登录成功不自动上传/下单/生图；下一步依据当前真实同意和余额。
原型无 Apple 服务，按钮明确叫“模拟登录”，不得直接移植到正式 App。

### M02 Data use / 处理同意
照片权利声明、FORM 上传存储、第三方 AI 共享目的要清楚区分。
生产文字候选：
`Upload this photo to FORM to create and save your look.`
`For this request, FORM sends the photo to {processorName} for AI editing.`
`I have the right to use this photo.`
`I agree to the described photo storage and AI processing.`
另有可访问的 Privacy / Terms / deletion 信息。
上述供应商、保留期限、政策版本未知时，不能用假的公司名称和“绝不训练/立即删除”填空；真实创建关闭。原型只确认“示例演示不上传”，不是生产有效同意。
这不是系统相机权限前的仿制预弹窗；系统选择权限仍使用原生组件。

### M03 Credits / 购买
- 在确有新创作需求且余额不足时打开；允许从账户余额入口主动查看。
- 保留当前意图摘要：例如 `Next edit: graphite wheels`。不把手机原图裁掉。
- 候选5/15次包，不默认选昂贵套餐，不在价格未知时显示虚构美元。
- 生产 CTA：`Buy {units} credits — {displayPrice}`；数字单位、币种、价格由 StoreKit 与后端批准目录匹配。
- 写明一次性购买、每次创建的次数、原作品仍可查看保存。不给尚未实现的4K/无限/去水印能力收费。
- pending / Apple已返回但服务端待确认：不再展示第二次购买按钮，解释“不要再次购买”，可以离开。
- 只有服务端持久确认交易已授予/已授予过才显示到账；结果为取消不显示成功。
- 买完回 Review，重新检查报价过期、基础图/能力/供应商是否改变。变化时展示差异，重新同意/确认。永不自动生图。

### S04 Task / 等待
- 保留基础图和请求摘要，不放模拟“结果预览”。
- queued：`Waiting to start. You can leave this screen.`；可取消但服务端决定与开始处理竞态。
- processing：`Creating your look. You can leave this screen.`；无虚假免费取消。
- uncertain：`Checking an interrupted request. We will not submit it again automatically.`；不是直接“失败，再买一次”。
- 30秒/90秒可补充分段提示，但只陈述“仍在处理”，没有测量就不给预计剩余时间。
- 客户端超过180秒不能自行退次/判失败/发第二次请求；服从服务端完成和核对规则。
- 离开后保留小任务条；若正在其他内容页完成，不抢走当前操作，显示“结果已就绪”。
- 只有在等待页且前台时可转结果页；后台完成在回来时恢复，拒绝通知权限不影响访问。
- 技术失败与 OUTPUT_UNCHANGED：先确认预留确已返还才显示 `Your credit was returned.`；不确定就 `Checking your credit balance.`
- Retry 先显示旧失败请求快照，再重新确认；从未因刷新自动换 submissionId。

### S05 Result / 结果
- 大图、原图/当前图切换；全车可见，不用炫酷背景掩盖车型变化。
- 服务端持久保存之后显示 `Saved to your garage`；收藏只是偏好标记。
- 主 `Save or share`，次 `Refine this look`；尝试新方向和报告问题是较轻的入口。
- 继续修改来自用户当前选定的那一版，不是自动选最后一版。
- 暂未图像质量检测时，只说 AI concept，不说“保真检测通过”。
- 图片加载失败提供重新加载/历史入口，绝不替换为示例图；已成功任务不重新生图、不重复扣次。
- 已有作品不因为试用结束/未购买新包被锁住。

### S06 Edit / 单项微调
- 基础图保持不动。点色块只改变草稿和清单，不伪装已应用。
- 首轮只展示能力已验证的 bodyColor / wheelColor。轮毂造型和表面材质后置配置，未验证就不出现可购买入口。
- 明确 `Keep current` 与 `Restore original` 不同；模型不支持恢复时不显示恢复按钮。
- 同一请求的多个允许改变一起收费1次；不能点击两种颜色就产生两笔后台请求。
- 可撤销/清空草稿，不覆盖原图历史。
- 用户想换颜色是新需求；模型没有按要求改是问题反馈，两者文案和处理不同。

### S07 Garage / 作品
默认展现用户自己作品、活动任务、未完成购买的恢复入口；不强制再次看品牌首页。
用户指定封面可以是旧版本；作品上标识版本/收藏，不自动把最新等同最好。
任意两个同项目版本比较不再生图。无作品时给“找到第一个方向”，不是空白页。
离线只显示按当前权限已缓存的图片；账号切换不显示前一账号缩略图。

### S08 Export / 导出与问题反馈
生产导出：干净图、前后图、竖屏方案卡；实际规格显示实际尺寸，不把插值放大叫原生4K。
系统取消分享不是成功发布；相册写入完成才写保存成功。用户主动外发之后不能承诺远程删除其相册副本。
反馈类目：不像我的车、没有按要求改、图像错误、个人不喜欢、太慢/失败。输入失败保留文字，不自动补偿或调用模型；正式反馈审批按F35。

## D. 视觉与交互约束

保持 FORM 原有安静、编辑工作室式方向，不换成游戏化霓虹控制台。
- 浅米白底 `#f7f8f3`；深墨绿正文 `#17241e`；灰绿次文字 `#5b685f`；主按钮黄绿 `#d4ed72`，深字；界线 `#dce1d5`。
- 系统字体；正文建议16–17pt，辅助信息13–14pt。示意原型有少量11pt标签，不应据此缩小生产告知文本。
- 页面间距20pt（窄屏16pt），卡片圆角18–20pt，主按钮最小52pt，所有必要点击目标≥44pt。
- 顶栏+正文滚动+独立底部操作区+导航，不用悬浮按钮挡住图片。短屏/大字采用整页纵向重排，不能同时让两个面板互相覆盖。
- 同一页面只有一个视觉最强主按钮；重要动作不用单独图标隐喻。
- 输入焦点、弹层焦点锁定、Esc/Back退出、返回调用按钮；颜色选中不能只靠颜色，还要勾选与 aria-pressed。
- Reduce Motion 保留可读状态，不旋转/自动扫图；首次比较不做会让人误以为生成的变形动画。
- 无左右横向滚动；320/360/375/390/430pt、横屏、200%文字应检查。浏览器模拟不替代真机 VoiceOver / Dynamic Type。

## E. 成功标准

本轮设计验收：主路径可独立走通，异常不会让人重复付费/重新开始，关键文案不误导，主操作在手机上可达。
不是“原型点得通就证明有人会买”。付费意愿、真实图片满意度和留存必须另测，不作为这份无模型原型已经证明的成果。
