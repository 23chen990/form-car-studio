# Mody × Modyfy × FORM：阶段化竞品对照与差异机会

**比较基准：** Mody＝`VIDEO01`、补充静态截图 `SCREEN01` 与官方商店；Modyfy＝`VIDEO02` 与官方商店；FORM＝仓库冻结 V2.2 决策与用户对 PR #5 的明确否定、上一轮 A/B 候选。不是第三方收入榜、个人喜好或未见的生成结果。

## 总结

Mody 提供三种创作入口与部件选择结构；Modyfy 用连续的车辆变更演示先激发想象，用四步流程承接提交，并大量陈列视频/娱乐特效。两者都重视“视觉营销 + 配置项 + 付费”；两段录屏**都没有出现针对该次用户输入的可验收模型成品**。FORM 应当找到**可证明的同车保真 + 明确改装方向 + 一次生成可解释成本 + 可持续小步修改**的产品位置，而不是比谁菜单多。

## 哪些特征“看起来先进”但不值得抄？

- **营销“1M+”“#1”**：Modyfy 展示了这些声称，不等于已核验，FORM 不应虚报规模。
- ** dozens 风格、复杂轮毂品牌/尺寸**：超出首版已验证模型能力，增加假承诺与维护成本。
- **娱乐化 Crash / Transformers / Video / 3D**：能制造传播素材，也可能增加第三方模型、版权与内容安全支出，偏离普通车主的刚需。
- **付费订阅转化链**：同样可能带来投诉；FORM 用户明确只授权次数包、试用关闭。
- **即时视觉预览**：录屏中缩略图或颜色网格不证明触碰色块就产生真实换色结果；用 CSS 给车身加滤镜冒充生成更危险。
- **“智能分析”进度**：没有实测结果/指标的动画不应借用发动机性能、空气动力学之类专业语言。

## FORM 具备的潜在差异，而不是既成事实

1. **一眼知道：改的是我这辆车，而不是另做一张梦幻车图。** 需要真实模型输出证据，不得先承诺。
2. **保留哪部分、修改哪部分有清楚选择**：选图之后完整显示底图和改动摘要；不要要求车主学会提示词。
3. **一次付费得到什么透明**：一张结果、一笔确切消耗、可以恢复/反馈/比较。
4. **从第一张满意图自然继续**：原图与每版历史可选；下一次是有意图的一笔新生成，不重写旧结果。

## 重要反证假设

“用户可能更爱夸张变形和娱乐短视频”“部分用户未必关心保真”“订阅可能在某些渠道更赚钱”。这些可能成立，但不符合 FORM 首版当前边界，且没有足够数据证明应切换方向。建议将它们留在研究假设区，而不是悄悄加进产品范围。

## 可以优先偷师的三种结构（不复制美术和文字）

1. Modyfy：普通街车大图 + 直接可理解的改色/轮毂变化。
2. Mody：复杂选项收到抽屉里，选中态明确，主画面留给车。
3. Modyfy：用户还没准备相册时可用示例继续探索；必须严格零生成浏览。

**共同原则：** 复制通用体验规律，不复制用户照片、商标、页面代码、具体艺术作品、私人提示词或声称。
