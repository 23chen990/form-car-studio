# Modyfy 付费墙、信任与“试用”风险专题

证据体系：视频 `VIDEO02`、苹果商店 `STORE_MODYFY_US`、用户评论 `REVIEW_MODYFY_US`。任何材料都**未授权 FORM 改成订阅或做真实试用**。

## 一、录屏事实

| 项目 | 录屏实见 | 解释/限制 |
|---|---|---|
| 出现时机 | 00:28 前后，还没完成用户照片上传就进入完整订阅营销页 | 属于“前置转化尝试”，不是生成后的付费 |
| 主要形象 | 大型车辆视觉、星级、蓝色标签、促销式周价换算，底部 Start Now | 大图增强视觉注意，不等于真实生成成品 |
| 7-DAY TRIAL | 明确显示 7-DAY TRIAL；随后 Apple 面板显示首周 US$7.99/周，之后 US$9.99/周 | **首周优惠付费，不是七日免费体验**；不能省略首周收费事实 |
| YEARLY | 另一个显示 YEARLY、US$39.99/year 及约 US$0.77/week 的选择 | 折算不是按周付费；以系统真实订阅面板为准 |
| 购买状态 | 00:34–00:37 打开 Apple 系统确认；随后返回 App | **未看见交易确认完成、扣款或权益到账** |
| 可退出性 | 页面上有 X，用户退出后能浏览创建/Effects | 不可称“完全强制付费才能浏览” |
| 第二次出现 | 01:50 左右在 Crash 模式中再次看到付费墙 | 只证明这段路径重复出现，不证明全量用户频率 |
| 声称“#1”“1M+” | 订阅宣传页上看见标签、星级与“1M+ Happy User” | 仅能记作**开发者营销声称**，没有独立验证 |

价格事实限于用户录制时的账号、地区、实验和商店情况，不是当前普适价目。不同套餐、地域、用户组可能不同。原始 Apple 邮箱/用户标识绝不可进公开仓库。

## 二、App Store 评价的独立交叉核查

美国商店页面：https://apps.apple.com/us/app/modyfy-ai-car-designer/id6762754163

截至本次阅读，可见多条评论针对“trial”理解不清、还没评估图像效果就要支付、活动价格之后转为较高周费表达不满；开发者公开回应将其描述为误解并邀请联系支持。也有好评提到上传图片后得到像样的视频效果。

**分清证据层级**：
- 商店页面与系统购买面板是可核对的**文字与价格展示**；
- 评论只代表少数评论者主张，不能证明所有用户抱怨、实际退款率或存在违法行为；
- 视频并无用户付款成功，也没有提供商店后台交易信息。
- App Store 展示的评分/评价数随时间与地区变化；不能用某时刻的星级推算付费转化。

这项外部交叉核查**支持“Trial 命名可能造成误解”这一风险，而不支持对竞品的定性控诉**。

## 三、FORM 的设计底线

**保持冻结的 V2.2 决策：** 首版按次购买、默认无真实免费试用、不购买外部模型预算、未获 Apple 商品信息前不显示虚构价格。不可因为竞品的订阅页诱导就替换既有商业政策。

让用户在“选图→草稿→报价确认”的路径上始终知道：
1. 这是基于**自己的某张图片/某个历史版本**，不是对宣传图的真实产出承诺。
2. 将改什么：车色/质感、整体方向、被验证支持的具体部件；哪些保持不变是意图，不承诺像素级精准。
3. 提交后原则上得到**一张结果**；真正服务端价目与权益在提交前明示。
4. 若余额不足，购买过程应展示实际商店报价和到账状态；支付成功也**不自动生图**。
5. Cancel/Restore 路径回到原草稿；购买待确认不能重复购买或默认完成。
6. 未经证据不喊“免费试用”“实时结果”“无限生成”“100% 精准”“官方推荐”。
7. 屏幕内不要模仿 App Store 原生购买确认；正式支付只使用受验证的 StoreKit 流程。

## 四、为什么这不只是合规问题

实际用户犹豫至少有四类：不信结果与原车一致、不信营销图、不了解价格、担心上传私人照片。**先付费有时可能提高初次营收，但本项目没有任何测试能证明它优于建立信任后的明示收费。** 对小体量产品，退款、不满意和差评可能比一次多一张成交更贵。这是需研究验证的商业假设，不是已测结论。

## 五、需验证的事项

- 产品后台真实商品：单次购买套餐、用户权益、退还和重复支付保护。
- 不依赖模型成本的真实价值证明：授权的同车 Before/After、修改部件细节放大、示例标记。
- 8–12 位目标车主无讲解访问首屏和付费确认，分别记录：对生成能力的信任、对价格的理解、是否主动选图、放弃的理由。
- 用户愿不愿意在知道“1 次=1 张、真实价格”的条件下继续，不用无价按钮测付费意愿。
