# 本次审查方法、隐私检查与限制

## 实际执行

1. 读取 GitHub 的 PR #3、分支列表、基线提交/树、既有 V2 分支树和 AGENTS/GitHub 工作流；研究目录与实施分支隔离。
2. 阅读用户提供的两份文本记录；不运行其中提到的 REA/Hopper。
3. 用 ffprobe 获取视频时长、尺寸、轨道；查看覆盖 0–104 秒的按秒缩略图，并在关键界面查看较大帧。
4. 重新用 ffmpeg 精确定位 8、17、24、37、42、54、62、70、78、83、90、94、101 秒，提取 13 张私有核对帧；没有使用 OCR。
5. 直接查看用户追加的 GARAGE 静态截图，单独记录来源限制。
6. 对原始 MP4、两份 TXT 和既有交付包计算 SHA-256；运行既有交付包自身校验器，输出 `VERIFIED 62 files`，退出码 0。

上述是抽帧视觉审查，不声称逐帧播放了全部视频，不声称亲自操作竞品或审查音频。按秒抽样可能漏掉短暂的中间状态，因此时间段仅作定位，非精确触摸轨迹。

## 可复查命令

仅在持有原文件的本地私有目录运行。不要把生成帧提交公开仓库。

```sh
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_type,width,height,r_frame_rate -of json RECORDING.mp4
ffmpeg -loglevel error -ss 83 -i RECORDING.mp4 -frames:v 1 -update 1 private-frame-83.png
sha256sum RECORDING.mp4 mody-static-report.txt mody-analysis.txt FORM_V2_REDESIGN_ZH.zip
python design/form-first-session-v2/tools/verify_package.py
```

最后一条命令属于上轮交付包，需在解压后的包中执行；该包的完整源码不在本研究目录内。工具应自行确认运行环境，不擅自安装依赖。
